# Milestones — the lab's curriculum

Each milestone is one night's run, one new piece of behavior or one new
measurement. Mark a finished milestone `[x]` with a `(done <date> — <result>)`
note when the report it produced is committed into `reports/`.

- [x] **M07** — Potts model (q-state). Run q = 3, 4, 5, 6. Phase transition is continuous for q ≤ 4 and first-order for q ≥ 5; show the qualitative change in your susceptibility curves. (done 2026-06-25 — all four exact T_c = 1/ln(1+√q) reproduced from the order-parameter χ peak on an L=64 square lattice, 25 temps per q in T_c±0.12, Wolff cluster updates: q=3 → 1.002 vs 0.995 (0.7%), q=4 → 0.907 vs 0.910 (0.3%), q=5 → 0.822 vs 0.852 (3.5%), q=6 → 0.749 vs 0.808 (7.2%); 471s on GPU. The continuous→first-order change is clear in the susceptibility curves: peak χ_max climbs monotonically 134 → 370 (continuous q≤4) → 824 → 1063 (first-order q≥5) — the taller, sharper spike of a discontinuous transition. Single-spin Metropolis is metastably trapped through this transition and reports noisy multi-peaked χ (a first attempt did exactly that); the **Wolff single-cluster updater** — Potts FK bond prob p=1−exp(−βJ), recolour the cluster to a random new flavour — fixes it, reusing wolff.py's cluster mechanics. q=5,6 are first-order with stronger finite-size/metastability shifts, so they carry a wider ±0.15 tolerance (vs ±0.1 for the continuous q≤4) — a physical allowance, not a fudge; both still land well inside it. The order parameter is the Potts m=(q·ρ_max−1)/(q−1).)
- [x] **M08** — 2D XY model. No long-range order at any T > 0, but a Berezinskii-Kosterlitz-Thouless transition at T_BKT ≈ 0.893. Measure the helicity modulus jump. (done 2026-06-25 — helicity-modulus jump crossing T_BKT(L=64) = 0.913 vs benchmark 0.8929, rel. err 2.2%; the spin stiffness Υ(T) crosses the Nelson-Kosterlitz universal-jump line Υ=(2/π)T at the transition, located by linear interpolation of the first downward root of Υ(T)−(2/π)T, 26 temps in [0.6, 1.1], 40k sweeps, 94s on GPU. This is the first model with **continuous** spins — angles θ∈[0,2π), E=−J·Σcos(θᵢ−θⱼ) — and the first transition with **no order parameter**: ⟨|m|⟩→0 at all T>0 (Mermin-Wagner), so the helicity modulus (free-energy response to a boundary twist), not a χ/C peak, is the signature. Estimator = the energy-like bond-cosine term minus the (β/N)-weighted *connected* variance of the bond current Σsin(θᵢ−θⱼ) — getting that 1/T factor and the connected form right is the #1 XY failure mode. Update: per-T-tuned-δ checkerboard Metropolis with interleaved microcanonical over-relaxation (the cure for XY critical slowing), which keeps Υ(T) smooth and monotone so the crossing is unambiguous; an embedded-Ising single-cluster Wolff (reflect across the line ⊥ a random axis — flipping the embedded ε, NOT reflecting across the axis itself) is available for the hardest near-T_BKT points. BKT has notoriously strong logarithmic finite-size corrections, so the single-L crossing sits a touch *above* the infinite-volume 0.8929 and the check carries a wider, physically-justified ±0.07 window — an L-extrapolation would sharpen it. The same single-L finite-size caveat as M05/M06 applies.)
- [x] **M09** — 2D Heisenberg (continuous spins). Confirm no phase transition in 2D (Mermin-Wagner). (done 2026-06-25 — the *absence* of order reproduced: at a fixed T=0.7 the per-spin vector magnetization ⟨|m|⟩ drifts 0.478 → 0.282 → 0.142 across L=16, 32, 64 (each step ×0.59, ×0.50 < 1; slope vs 1/L = +7.05 > 0, so ⟨|m|⟩ → 0 as L → ∞), 20k sweeps/L, 250s on GPU. This is the rare milestone whose *correct* answer is a NEGATIVE one — Mermin-Wagner forbids a 2D system with a continuous (here O(3)) symmetry from spontaneously ordering at any T > 0, and unlike the XY model (M08) the Heisenberg sphere S² is simply connected (π₁=0, no stable vortices), so there is no BKT escape either — no transition of any kind at finite T. The falsifiable signature is the finite-size drift of ⟨|m|⟩ toward 0; reading a single small L instead would fake an appreciable ⟨|m|⟩ and a spurious transition (the #1 way this ships wrong), so the run varies L and check_m09 asserts the monotone decrease + positive 1/L slope. The energy per spin is L-independent (≈ -1.15 at every size — an intensive quantity), the receipt that it's the order parameter washing out, not the lattices sitting at different states. New O(3) engine (heisenberg.py): 3-component unit-vector spins, E = −J·Σ S_i·S_j, **uniform-on-sphere** sampling (z=cosθ ∈ [−1,1] uniform, φ ∈ [0,2π) — NOT θ-uniform, which pole-biases and corrupts every energy/correlation), per-T-tuned-δ checkerboard Metropolis with interleaved microcanonical over-relaxation (reflect S about the local field — the cure for spin-wave critical slowing at the low-T, large-ξ points), plus an embedded-Ising single-cluster Wolff (reflect across the plane ⊥ a random axis — flipping the embedded ε, NOT reflecting through the axis itself, the recurring O(n)-cluster subtlety). A reproduced *known absence* earns the green leaf, distinct from an [~] failed calibration — the null IS the calibrated answer here.)
- [x] **M10** — Antiferromagnetic Ising on a bipartite lattice (same as ferromagnetic by sign-flip — sanity check the framework handles negative J cleanly). (done 2026-06-25 — staggered χ_s-peak T_N(L=128) = 2.282 vs Onsager exact 2.2692, rel. err 0.5%; specific-heat peak independently at 2.276 from the same run, 25 temps in [2.0, 2.6], 40k sweeps, 30s on GPU. J=−1 (antiferromagnetic) on the square lattice: by the bipartite sublattice gauge flip s_i→−s_i (on one colour) the AFM is *exactly* the ferromagnet in disguise, so the Néel point is Onsager's same T_c — the framework handles negative coupling cleanly. The order parameter is the **staggered** magnetization m_s = (1/N)Σ ε_i s_i with ε=(−1)^(x+y); its susceptibility χ_s peaks at T_N. The headline trap: the **uniform** ⟨|m|⟩ stays ≈0 at all T (≤0.003 across the whole sweep — the Néel state carries no net moment), so reading uniform m would show nothing and look broken. The square lattice is bipartite and unfrustrated, so the plain red/black checkerboard is exact — NO 3-colouring (that was M05's *frustrated* triangular problem; the frustrated triangular AFM is the later M13). Strongest correctness guard: an AFM↔FM gauge-duality cross-check test — the AFM's staggered observables equal an FM run's uniform observables bond-for-bond at the same |J|/seed (catches a silent ΔE sign-error that would secretly revert to the FM). The only code change from ising.py is the sign of J in ΔE; ising.py is untouched and its _neighbor_sum reused. The finite-L peak sits just above the infinite-volume value, as expected — the same finite-L peak caveat as M04 applies.)

## Phase 3 — push the edge (M14 done — the frontier crosses into Phase 4)

- [x] **M11** — Edwards-Anderson spin glass on a 2D square lattice. Run many disorder realizations, measure the disorder-averaged overlap distribution P(q) between two replicas. **In 2D the EA glass sits at the lower critical dimension — its spin-glass transition is at T_c = 0, so there is NO finite-temperature glass phase.** The verification is therefore the *approach to the T = 0 critical point*: P(q) broadens (its width / ⟨q²⟩ grows) monotonically as T → 0, without a finite-T transition. (The finite-T transition — T_SG ≈ 1.10 for ±J couplings, with a Binder-cumulant crossing — is the **3D** case — that's M12, not this. The original "develops structure at low T" phrasing was corrected to the T_c = 0 framing in the M11 PR.) (done 2026-06-25 — the broadening reproduced: the disorder-averaged ⟨q²⟩ grows monotonically 0.011 → 0.306 (×27, 15/15 temperature steps) as T falls 2.0 → 0.6 on an L=16 ±J lattice, 16 temps × 64 disorder realizations × 2 replicas in one batched GPU pass, 60k sweeps, 67s; the overlap stays symmetric (max|⟨q⟩| = 0.045 ≈ 0, P(q)=P(−q) residual 0.061), and the Binder cumulant rises smoothly 0.01 → 0.71 with no crossing — single-L, consistent with T_c = 0. This is the rare milestone (like M09's Mermin-Wagner null) whose *correct* answer is an expected behaviour, not a transition temperature — the known T=0-critical broadening reproduced earns the green leaf. The order parameter is the replica overlap q=(1/N)Σ s_i^α s_i^β between two replicas sharing the same quenched ±J bonds; the disorder average over many realizations is mandatory. Equilibration floor: single-spin checkerboard Metropolis cannot equilibrate the L=16 glass below T ≈ 0.5–0.6 (verified — even 4× burn-in leaves the coldest points in an under-equilibration *dip* where ⟨q²⟩ is suppressed, not enhanced; the textbook reason parallel tempering exists), so the trustworthy window starts at the floor T=0.6 and the broadening *trend toward T=0* is the claim, not the un-equilibrable T≲0.5 tail. **Parallel tempering did reach colder — 2026-08-19.** The sentence above was a prediction, and it was tested. Extension run `reports/2026-08-19-m11.html`, receipt `reports/receipts/run-2026-08-19-2111-m11.json`, stamped to a clean tree at commit `352ff3c`: with a replica-exchange move every 50 sweeps the same L=16 ladder runs down to **T = 0.30** — six rungs below the floor above — and ⟨q²⟩ grows monotonically to **0.476** with **15/15 steps broadening**, max|⟨q⟩| = 0.014, in 151 s on CUDA. It cost nothing: in the four-arm benchmark that motivated it, the tempered ladder ran 75.7 s against the untempered 78.3 s. **The arm that settled it was the one that failed.** Quadrupling the burn-in to 120,000 sweeps, at twice the wall-clock, left the dip exactly where it was — which is what this entry already predicted in June, and the reason the wall was never compute. It was the move.

  Three guards separate an equilibration fix from a sampler that simply makes cold numbers bigger. The warm end (T ≥ 0.75) is unchanged across all four arms to three decimals, so tempering alters the answer only where single-spin dynamics was stuck. Two exchange intervals differing 5× agree to three decimals. And on a 4×4 lattice, where all 65,536 states can be summed, the sampler reproduces the exact Boltzmann ⟨E⟩ at every rung with the move on and with it off — so a wrong acceptance rule or a broken detailed balance would have shown up before any of this ran.

  **Both ladders are published.** The run carries the untempered sweep beside the tempered one under `comparison` — same seed, same disorder realizations, differing only in whether configurations could change temperature. That ladder turns over at **T = 0.527** with max|⟨q⟩| = 0.097 and only 87 % of its steps broadening. The June numbers are not quietly restated; the dip is now on the shelf next to the result, which is where it belongs — it is the measurement that says what the old sampler could and could not see. `check_m11` refuses any report below T = 0.6 that carries no exchange move, with the floor owned by the check rather than read from the run, so a run cannot widen its own trustworthy window.

  **Boundary.** T = 0.30 is where this run stopped, not where the tempered floor sits — nothing here locates the new floor, only that the old one is no longer binding. The ladder is over-resolved (minimum adjacent acceptance 0.472, above the usual 20–40 % band), so some of the 16 rungs are buying nothing, and acceptance falls with lattice size, so this ladder will not simply carry to L = 32. And there is no new physics here: ⟨q²⟩ growing toward T = 0 is the published behaviour of this model, and replica exchange is roughly 35 years old — `peapods` (arXiv:2602.19045) ships it alongside Houdayer cluster moves this lab does not have. The result is instrumental. A windowsill adopted a standard sampler and measured what it bought, which is six rungs of a curve the milestone previously had to stop short of. Detail and the four-arm benchmark: `docs/investigations/2026-08-19-parallel-tempering-lifts-the-floor.md`; prior art graded in `docs/assays/2026-08-19-fold-gates-and-tempering-prior-art.md`. The square lattice stays bipartite under random bonds (frustration is in the bond signs, not the geometry), so the red/black checkerboard update is still exact; the load-bearing bookkeeping is the J-weighted neighbour sum — left/up bonds come from the *rolled* coupling tensors — verified against a brute-force bond energy.)

- [x] **M16** — Aging in spin glasses: after a quench, two-time correlator C(t, t_w) should depend on t/t_w only (aging) or only on t-t_w (equilibrium). # The coherence book

The M ladder asks when a lattice of **spins** agrees. This one asks the same
question of **clocks**: N oscillators, each running at its own natural frequency,
each nudged toward the crowd. It is the second physics ladder in the lab, and it

is known exactly), then map, then push into the open.

nightly instrument. That work already ran on the order-parameter susceptibility
χ(K) = N·Var(r); K01 is the rung underneath it, proving the same estimator finds

Boundary: identical oscillators, all-to-all, excitatory, zero delay — nothing is claimed about frequency disorder, local topology, delays, or inhibition.

# The Citizen Science book

The physics ladder above proves the lab can be trusted. This book points that
trust *outward* — at real contributions a single patient machine can make to
science that other people use. Same rule as the physics: **calibrate first**
(reproduce a known result), then contribute, then submit to the official record.
See [CITIZEN_SCIENCE.md](CITIZEN_SCIENCE.md) for venues, contributor IDs, and the
provenance/DOI workflow. IDs are track-prefixed (C/A/I/B) and a verified
contribution carries its record as `{venue=… ; url=… ; doi=…}`.

## Track P — the folding problem

- [?] **P01** — **Fold HP lattice sequences blind and recover ground states proven in-house.** (measured 2026-08-24, machine gate PASSED, awaiting human review.) Dill's hydrophobic-polar model on a 2D square lattice: a chain of H and P beads folded as a self-avoiding walk, energy = −(H−H contacts that are lattice neighbours but NOT chain neighbours). Finding its ground state is NP-hard, which is why it survived thirty years as the benchmark folding methods are measured on. **The target is computed here, not cited.** For chains short enough that every self-avoiding walk can be visited, exhaustive enumeration PROVES the optimum — so nothing in the gate depends on a number anybody remembered, which is the failure `safety/pz-facts.md` was shrunk over. A replica-exchange Monte-Carlo search (pivot moves on a temperature ladder, the same shape M12's spin glass uses and for the same reason: rugged landscape, single cold chains freeze into the first funnel) is then run blind against the same sequence and has to find what enumeration proved. **Three controls, each answering a different doubt:** enumeration answers *is the target real* (proven, with the node count carried in the receipt so "exhaustive" arrives with its own cost); **parity** answers *is the energy function even right* — a square lattice is bipartite, so a sequence whose H beads all sit on one sequence parity can have EXACTLY zero H−H contacts by geometry, no fit and no tolerance, and both enumerator and sampler must return 0; **shuffle** answers *does the search work on a sequence nobody designed* — the same beads scrambled, enumerated and folded under an identical budget. **The receipt is the fold itself:** every conformation carries its coordinates, so `check_p01` re-validates self-avoidance and recomputes the energy from geometry, and re-runs the enumeration, rather than trusting any number in the file. **A control of mine died here and the correction is the interesting part:** the first draft graded a shuffle that folded LOWER than the original as a failure, reasoning that composition should not beat arrangement. The run refuted it — HHHPPPHHHPP has optimum −2 while the permutation PHHHPHPHHPP reaches −3, because clustering hydrophobics genuinely lowers energy. That IS the model's physics, so the gate now asks the only question a control can honestly ask: whether the search recovers the proven optimum of whatever it is handed. **Boundary:** a coarse-grained lattice abstraction of hydrophobic collapse; recovering its ground states says nothing about real tertiary structure and no claim about actual proteins is made or implied. Longer chains (L=20, 24) are reported as *best found* and kept in a separate list from the graded set, because enumeration is out of reach there and an unproven optimum must never be pooled with a proven one. ## Conventions

- Each milestone PR includes the report it generated (drop the HTML +
  JSON into `reports/`).
- Don't burn weeks of compute without checkpointing — every long run
  writes intermediate JSON every N samples.
- A milestone that doesn't reproduce a known result is a failed
  calibration, not a discovery. Verify before claiming. Mark it `- [~]`
  (instead of `- [x]`): it stays on the books as a recorded null and shows
  up as a folded grey leaf on the [seed](https://www.brokenbranch.dev/windowsill/),
  not a green one.
- Phase 4 results that LOOK novel get a second pass from a real physicist
  before sharing.
- The checkboxes here are the single source of truth for `lab publish`:
  `[x]` → human-promoted/verified, `[?]` → measured + machine-checked but
  awaiting review, `[~]` → failed or inconclusive calibration kept as a null,
  `[>]` → the explicitly-chosen open experiment (any track; add
  `{progress=0.4}` to show how far along it is — without a `[>]`, the first
  pending milestone is promoted to open automatically),
  `[ ]` → pending (the first pending is the open question on the bench).
