# Pre-registration — U-A01 attempt, TESS sector 96

**Committed before any light curve from sector 96 was opened.** That ordering is
the whole point of this document, and it is checkable: this file's commit must
precede the hunt receipt's `generated_at`.

## Why this file exists

U-A01 was recorded as ATTEMPTED on 2026-08-24 and the lab corrected itself the
next day:

> ⚠ This was first recorded as an ATTEMPT and it is not one. It consumed only
> committed bytes; no new observation was acquired. U-A01 asks whether the
> *sector* holds an uncatalogued transit — this answered whether the *record*
> does, which the empty shelf had already said. … *the care went into the asking,
> and it stopped at the looking.*

So the bar is: **go outside**. New data this box has never seen, searched with a
rule fixed in advance.

## The question

Does TESS sector 96 contain a transiting planet signal that has not been
catalogued?

## The sample

- **Sector 96.** Chosen because it is recent — the community has had less time to
  work it — and because this box has never touched it. Every committed hunt
  receipt here is sector 2, 3 or 30 (76 receipts). Sector 96 appears in exactly
  one prior artifact, A01's multi-sector WASP-18 b photometry, which is a single
  named target and not a search.
- **n = 500** two-minute-cadence targets, drawn by the driver's existing
  consistent-hash sample so the draw is reproducible and stable under pool
  changes (the defect A04 found and fixed).
- Targets already searched in any prior artifact are excluded by
  `scripts/a05_hunt.py:prior_targets()`.

## The decision rule, fixed now

1. **Detection threshold: SDE ≥ 8.0** (`a04.SDE_THRESHOLD`). Not chosen here and
   not a free parameter — it is the committed constant, and the run refuses if
   the measured false-alarm floor closes the gap beneath it. The pooled null
   behind it is 84,500 scramble draws with a maximum SDE of **8.049**, so a
   crossing carries a *measured* false-alarm probability rather than an
   extrapolated one.
2. **Per-target FAP** from the dual-scheme permutation null, graded on the
   conservative empirical bound.
3. **The machine cannot emit `planet`.** The terminal machine state is
   `lead-awaiting-human-review`; everything else in `a05_vocab.MACHINE_DISPOSITIONS`
   is a refutation or a catalogue match.
4. **Catalogue cross-check runs at report time, never in the search.** A TOI
   match with disposition FP is `toi-known-fp` — not a recovery and not a lead.
5. **Placebo controls** (uniformity, epoch scramble) must pass or the slice is
   withheld: `to_report` refuses an incomplete run rather than shipping a partial
   survey as a whole one.

## What each outcome means, agreed in advance

| Outcome | Verdict for U-A01 |
|---|---|
| One or more `lead-awaiting-human-review` | **unresolved** — a lead is not a planet; it goes to a human, and the entry records that the sector produced a candidate the catalogue does not carry |
| Every crossing refuted or catalogue-matched | **killed** — sector 96 holds no uncatalogued transit this instrument can see, at this sample and this threshold |
| Zero crossings above threshold | **killed**, same reading, with the completeness caveat below |
| Controls fail, or the budget stops the run mid-slice | **no verdict** — the run is withheld and this attempt does not count |

**An empty shelf is a result.** G01 says in its own text that `killed` or
`unresolved` satisfies it exactly as well as `supported`. Nothing here is
optimised for finding something.

## Boundaries, stated before the data

- A **sample** of sector 96, not the sector. No completeness or occurrence-rate
  statement is implied by anything this run produces.
- A lead is a lead. No discovery is claimed, nothing is submitted to ExoFOP, and
  the machine's own vocabulary forbids the word `planet`.
- Absence of a detection in 500 targets is not absence in the sector.
- Depths are reported and never graded — the running-median detrend biases them
  low for long transits.

## Falsifiability

If the run returns a lead, the claim to check is the dossier under
`reports/hunts/dossiers/`, and the first question a reviewer should ask is the
one that caught TIC 77044472: *is this a real planet on the wrong star?* The sky
gates (blend, neighbour crosscheck, companion radius) run before any lead is
emitted, and their verdicts are in the receipt.
